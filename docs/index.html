For people who build with AI coding agents

Every session picks up where the last one left off.

Coding agents forget everything between sessions. Agentbook fixes that. It keeps a handbook next to your code with every decision, every question you asked and its answer. Your agent reads it first and keeps it up to date, on any computer, with any agent.

├── STATUS.md          where things stand, the next step
├── DECISIONS.md       every decision and why
├── history/sessions/  every question and answer, per day

§ 03

The routine is four sentences.

  1. 1

    Open

    Open the project folder in your agent. On a new computer, clone your private repo first.

  2. 2

    Work

    Say what you want. Ask about the past: did we look into…?

  3. 3

    Save

    Say commit and push. The handbook travels with the code.

  4. 4

    Stop

    Say wrap up. Even talk-only sessions reach your next computer.

§ 04

A small command for the moments that are yours.

Your agent runs the kit for you. agentbook covers the human parts: starting a project, seeing where it stands, searching the past, and checking it's all saved before you close the laptop.

§ 06

    
Say it, and it's done.

    
Each one starts with something you say to your agent.


    
Getting started

    

      
Start a brand-new project
        
Run agentbook init in an empty folder, or say:
Set up an agentbook for this project using github.com/EnigmaticZee/agentbook; follow its PROMPT.md.
You get one repo with the handbook and an empty code folder. Nothing goes online until you decide.

      
Add it to a project you already have
        
Same thing, inside the project. It asks before moving anything. The folder stays where it is, your code moves into a code folder with all its history, and the agent writes the handbook from what's already there.

    


    
Every day

    

      
Continue on another computer
        
Copy (clone) your private repo and open it in your agent. It sets everything up before it starts.

      
Ask about something from before
        
Did we talk about a phone app? Why did we drop the newsletter idea?
The agent looks it up in the handbook and tells you where the answer came from. Or search yourself with agentbook find.

      
A push is stopped
        
Usually nothing to do: the agent updates the notes or fixes the tests and tries again. To push anyway, say push without the checks this time.

    


    
Sharing

    

      
Put it on GitHub, privately
        
Put this project on private GitHub.
One private repo with the handbook and the code. It can stay like this forever.

      
Make it public
        
Get this ready to go public.
It shows you exactly what would be published (only the code), checks it for passwords, personal details and private files, and goes through anything it finds with you. Only after your yes does the code get its own public repo.

      
Someone else contributes
        
They only ever see the public code. Your handbook isn't there for them, and nothing changes for you.

    

  


  

    
§ 07

    
Install.

    

      

        
        
        
        
      

      
Set up an agentbook for this project using github.com/EnigmaticZee/agentbook; follow its PROMPT.md.
Paste it into any coding agent, in a new or existing project folder. Nothing else to install.

      
go install github.com/EnigmaticZee/agentbook/cmd/agentbook@latest
Installs the agentbook command from source. Then run agentbook init.

      
brew install enigmaticzee/tap/agentbook
macOS and Linux. Available from the first release.

      
curl -fsSL https://enigmaticzee.github.io/agentbook/install | sh
Downloads the latest release and checks its checksum (read the script). Available from the first release.

    

    
Needs git and bash, which most developer computers already have. Works with Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Amp, Jules, Zed and anything else that reads AGENTS.md.
